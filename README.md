# Sophisticated Backpacks - Digital Storages Expansion

Connect your Sophisticated Backpack to **Applied Energistics 2, Refined Storage, or Tom's Simple Storage**. Send collected items straight to storage, replenish your building supplies, and draw food and consumables from your network while you play.

Each item upgrade can be linked to any of the three storage systems. Link it to the network you want to use, install it in your backpack, and configure it through its upgrade tab.

## Linking an upgrade

Hold the upgrade and **Shift-right-click a compatible storage block** to link it, then place it in a backpack upgrade slot. Remote access respects your network's range and access rules, including its wireless setup.

Link the upgrade to another compatible block whenever you want to change networks. To remove its link, place the upgrade by itself in a crafting grid.

Craft each Remote Upgrade using its matching advanced Sophisticated Backpacks upgrade, diamonds, Ender Pearls, and redstone. It replaces the original upgrade for that function in your backpack.

## Works with your storage setup

Requires **Sophisticated Backpacks** and **Sophisticated Core**.

| Storage mod | Item upgrades | Remote Pump |
| --- | --- | --- |
| Applied Energistics 2 | Supported | Supported |
| Refined Storage | Supported | Supported |
| Tom's Simple Storage | Supported | No fluid support |

Use one supported storage mod or several together. Each upgrade keeps the network you link it to, so different upgrades in the same backpack can serve different networks.
