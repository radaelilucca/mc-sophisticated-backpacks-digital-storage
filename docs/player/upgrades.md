# Upgrade catalog

All eight upgrades use the same item-linking system and can connect to AE2, Refined Storage, or Tom's Simple Storage. SCC 1.5.3 or newer is also supported on NeoForge 1.21.1. Fluid transfer is supported by AE2 and Refined Storage on both loaders, and SCC on NeoForge; Tom's Simple Storage is item-only.

| Upgrade | Function |
| --- | --- |
| Remote Deposit | Use the tab button to deposit filtered backpack items into the linked network. |
| Remote Restock | Use the tab button to retrieve filtered network items into the backpack. |
| Remote Pickup | Route newly collected, matching items to the backpack or network. |
| Remote Magnet | Collect nearby matching item drops and route them to the backpack or network. |
| Remote Refill | Replenish configured player inventory slots from the backpack or network. |
| Remote Feeding | Feed the player carrying the backpack with configured food when hunger or injury conditions are met. |
| Remote Alchemy | Automatically use configured consumables when each filter slot's condition is met. |
| Remote Pump | Transfer filtered fluids between the backpack tank or network and containers, nearby fluid handlers, or world fluids. Tom's Simple Storage is item-only. |

See [Linking upgrades](linking.md) and [Filters and source priority](filters.md) for setup and configuration details. Full in-game validation of SCC gameplay is still pending.
