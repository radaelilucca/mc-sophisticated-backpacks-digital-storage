# Upgrade catalog

All eight upgrades use the same item-linking system and can connect to AE2, Refined Storage, or Tom's Simple Storage. SCC 1.5.3 or newer is also supported on NeoForge 1.21.1.

| Icon | Upgrade | Function |
| --- | --- | --- |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_deposit_upgrade.png" alt="Remote Deposit" width="32"> | Remote Deposit | Use the tab button to deposit filtered backpack items into the linked network. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_restock_upgrade.png" alt="Remote Restock" width="32"> | Remote Restock | Use the tab button to retrieve filtered network items into the backpack. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_pickup_upgrade.png" alt="Remote Pickup" width="32"> | Remote Pickup | Route newly collected, matching items to the backpack or network. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_magnet_upgrade.png" alt="Remote Magnet" width="32"> | Remote Magnet | Collect nearby matching item drops and route them to the backpack or network. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_refill_upgrade.png" alt="Remote Refill" width="32"> | Remote Refill | Replenish configured player inventory slots from the backpack or network. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_feeding_upgrade.png" alt="Remote Feeding" width="32"> | Remote Feeding | Feed the player carrying the backpack with configured food when hunger or injury conditions are met. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_alchemy_upgrade.png" alt="Remote Alchemy" width="32"> | Remote Alchemy | Automatically use configured consumables when each filter slot's condition is met. |
| <img src="https://raw.githubusercontent.com/radaelilucca/mc-sophisticated-backpacks-digital-storage/main/docs/gallery/upgrades/remote_pump_upgrade.png" alt="Remote Pump" width="32"> | Remote Pump | Transfer filtered fluids between the backpack tank or network and containers, nearby fluid handlers, or world fluids. Tom's Simple Storage is item-only. |

See [Linking upgrades](linking.md) and [Filters and source priority](filters.md) for setup and configuration details.
